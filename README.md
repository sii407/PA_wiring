# PA配線図エディタ 使い方ガイド

音響（PA）システムの配線図をWebブラウザ上で作成・編集し、PDF出力（印刷）やJSONデータとして保存・復元ができるWebアプリケーションです。

## 基本的な操作方法

### 機材・要素の追加
ヘッダーのボタンからキャンバス上に新しい要素を追加できます。

* **[＋機材]**: ミキサー、アンプ、イコライザー、スピーカーなどの機材ブロックを追加します。
* **[＋区切り線]**: ステージとPA席などを区切るエリア線（Box等）を追加します。
* **[＋テキスト]**: 「楽器類」などの補足説明用テキストを追加します。

### 要素の移動とドラッグ操作
* キャンバス上の機材やテキストをクリックし、ドラッグすると好きな位置へ移動できます。
* 位置合わせがしやすいよう、移動時はグリッド（10px単位）に吸着します。


## 配線（ケーブル接続）の操作

### 接続の作成
1. ヘッダーの **[接続モード]** ボタンをクリックしてオン（アクティブ表示）にします。
2. 接続したいケーブル種別をドロップダウン（`XLRケーブル`, `TRS-XLR`, `スピーカーケーブル` など）から選択します。
3. 接続元の機材をクリックし、続けて接続先の機材をクリックすると直線で配線が引かれます。

### 配線位置・形状の自由カスタマイズ
配線線をクリックして選択すると、**緑・赤・青の操作ハンドル**が表示されます。

* **始点ハンドル（緑色）**: ドラッグすると、ケーブルの開始位置（端子位置）を自由に変更できます。
* **終点ハンドル（赤色）**: ドラッグすると、ケーブルの終了位置を自由に変更できます。
* **中継点ハンドル（青色）**: ドラッグすると、線を好きな方向へ折り曲げたり、障害物を避けるルートへ調整できます。
* **[＋中継点を追加]**: 右側のパネルから中継点を追加すると、さらに細かく迂回させることができます。


## 詳細設定（サイドバーパネル）

機材や配線をクリックすると、右側のパネルから各種設定が変更できます。

### 機材の設定
* **名称・型番**: 1行目（メーカー/名称）および 2行目（型番）の書き換え。
* **入力チャンネル**: ミキサー等の入力ch（例: `1: 下手Vo`, `2: センターVo`）の追加・編集・連番生成。
* **出力端子（外側突起）**: ミキサー右側に突き出す出力ボックス（例: `STout-L`）の追加・編集。

### 配線の設定
* **ケーブル種別**: XLR、TRS、スピコン等の種類変更（線の色や太さ、破線が自動更新されます）。
* **[配線位置を自動に戻す]**: 手動で変更した始点・終点・中継点をリセットし、初期状態の直線へ戻します。


## その他の便利な機能

* **↩️ 元に戻す（Undo）**:
  * ヘッダーの **[↩️ 元に戻す]** ボタン、またはキーボードの **`Ctrl + Z`**（Macは **`Cmd + Z`**）で、直前の操作を取り消せます。
* **PDF出力 (印刷)**:
  * **[PDF出力(印刷)]** ボタンを押すと、サイドバーやヘッダーを自動で非表示にし、A4横サイズで綺麗に印刷・PDF保存ができます。
* **データの保存と復元**:
  * 編集内容はブラウザ（LocalStorage）に自動保存されます。
  * **[JSONコピー]**: 現在のデータ構造をテキスト（JSON）として保存・共有できます。
  * **[JSON読み込み]**: 保存したJSONテキストを貼り付けて復元できます。
